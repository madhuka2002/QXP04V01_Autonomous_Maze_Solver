# About

## Project

QXP04V01 - Autonomous Maze Solver

## Description

QXP04V01 is part of the Quantheonix Robotics research roadmap. The project demonstrates autonomous navigation inside unknown indoor mazes using only onboard proximity sensors.

The robot detects surrounding walls, makes navigation decisions using the Left-Hand Rule, recovers from dead ends, and controls movement through a Finite State Machine.

Unlike advanced navigation systems, this version intentionally avoids mapping and localization to focus on reliable low-level autonomous navigation.

## Objectives

- Learn autonomous robot navigation
- Implement a Finite State Machine
- Practice wall-following algorithms
- Build a foundation for future mapping and SLAM projects

## Hardware (Simulation)
